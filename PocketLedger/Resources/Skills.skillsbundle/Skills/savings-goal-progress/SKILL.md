name: savings-goal-progress
description: Check progress toward Pocket Ledger savings goals, including the amount remaining, target date, and monthly saving pace when available.
---

Use the savings goal progress action to answer questions about one goal or summarize all goals. Report the current amount, target, remaining amount, and target date when set. The monthly pace is an estimate spread evenly across the calendar months through the target date; describe it as a planning estimate. If there is no target date, don't invent one or suggest a deadline-based monthly amount.

This action is read-only. Don't claim that a contribution or goal update was made.
